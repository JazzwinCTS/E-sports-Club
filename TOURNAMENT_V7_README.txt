NEXTGEN TOURNAMENT V7 — INSTALLATION

1. Copy every folder and file in this ZIP into the root of your E-sports-Club project.
2. When Windows asks, choose Replace the files in the destination.
3. Open tournaments.html through VS Code Live Server.

PRESENTATION LINKS

Normal tournament page:
  tournaments.html

Simulated live broadcast:
  tournaments.html?demo=live

Completed broadcast result:
  tournaments.html?demo=final

The LIVE label and changing scores are clearly marked as a coursework simulation.
The YouTube trailer used by the player is:
  https://www.youtube.com/watch?v=d8N2FT2jTyU

To replace the video later, edit liveVideoId in data/youth-tournament.json.
