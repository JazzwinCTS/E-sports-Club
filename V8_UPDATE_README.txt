NEXTGEN PLAYERS + TOURNAMENTS V8 UPDATE
========================================

This is an update package for the existing Players/Tournaments project.
Copy every folder and file into the project root and choose Replace when asked.
Do not delete the existing PlayerPhotos, TeamLogo, GameLogos, vendor or font folders.

Main V8 changes
---------------
- Player directory now changes its full section background with the selected game.
- Weekly MVP uses a game-specific background and a cleaner player presentation.
- MVP identity card now shows only the team logo and Player ID.
- The Why They Won block was removed and View Player Profile is centred.
- Player profile portraits were moved upward while keeping the original layout.
- Tournament hero now uses a new original high-definition fictional arena image.
- The total prize pool card has a stronger gold presentation.
- Division rewards are Champion RM10,000, Runner-up RM6,000,
  Third place RM3,000 and MVP RM1,000.
- Best Play was removed.
- VALORANT, Counter-Strike 2 and PUBG backgrounds are clearer and more visible.
